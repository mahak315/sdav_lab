# Statistical Data and Visualization Lab

## 📌 About the Repository

This repository contains programs, experiments, and lab assignments completed as part of the **Statistical Data and Visualization Lab** for the AIML (Artificial Intelligence and Machine Learning) curriculum.

It serves as a collection of practical implementations of statistical concepts, probability distributions, data analysis techniques, and visualization methods using programming.

## 🎯 Objectives

- Understand and implement fundamental statistical concepts.
- Perform statistical calculations and analyze datasets.
- Explore probability distributions and their applications.
- Visualize data using graphs, charts, and plots.
- Develop interactive applications for statistical learning.
- Strengthen practical programming and data interpretation skills.

## 📂 Repository Contents

This repository includes:

- **Statistical Programs:** Implementations of statistical methods and calculations.
- **Probability Distributions:** Programs involving Binomial, Poisson, Geometric, and other probability distributions.
- **Data Visualization:** Graphical representations of data using appropriate plotting libraries.
- **Data Analysis:** Programs for exploring, processing, and interpreting datasets.
- **Lab Assignments:** Regular laboratory tasks, experiments, and practical exercises.
- **Interactive Web Applications:** Educational applications that demonstrate statistical concepts through dynamic calculations and visualizations.

The repository will be updated regularly as new lab exercises and assignments are completed.

## 🛠️ Technologies Used

Depending on the experiment, the repository may use:

- **Python** — Statistical computations and data analysis.
- **NumPy** — Numerical computations.
- **Pandas** — Data manipulation and analysis.
- **Matplotlib / Seaborn** — Data visualization.
- **Scikit-learn** — Selected statistical and machine learning techniques.
- **HTML, CSS, JavaScript** — Interactive web applications.
- **Jupyter Notebook** — Interactive coding, experimentation, and documentation.

## 📊 Topics Covered

- Descriptive statistics
- Probability and random variables
- Discrete probability distributions
- Mean, variance, standard deviation, and other statistical measures
- Probability Mass Function (PMF) and Cumulative Distribution Function (CDF)
- Data visualization and graphical analysis
- Dataset exploration and interpretation
- Practical statistical experiments
